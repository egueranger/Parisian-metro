# Parisian-metro
parisian_metro.py provides some functions to compute expected route time between two stations on a given line and transfer time between two given lines in a hub.

parisian_network.py displays the parisian network on a map with tailored colors and thicknesses. Final maps for different scales with Île-de-France.png, paris.png and paris2.png

All datasets are available on data.iledefrance-mobilites.fr.
